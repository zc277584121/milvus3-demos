## 已确定的范围

电影 Demo 使用常见的找片场景，允许采用原创虚构电影、剧情和海报；当前草图使用虚构内容。近重复检测 Demo 明确采用 MinHash + LSH，Embedding + ANN、Range Search 和聚类去重尚未决定是否实施，不纳入本轮设计范围。

MinHash 的随机排序类比可以作为后续文章或视频的讲解开场，在线页面不展示随机排列、指纹数组或算法推导。页面聚焦输入内容、候选结果、相似度阈值和文本差异。

两张图采用现有三个 Demo 的共同设计语言：浅色背景、白色卡片、紧凑顶栏、Milvus 3.0 标识、英文界面、预设输入和 GitHub Source 入口。它们分别突出分组浏览与差异检查，不增加通用后台管理侧栏或大幅营销横幅。

## 本次交付与后续边界

本次仅保存设计文档和静态图，不创建应用代码、数据库 Collection、模型或数据集，也不修改部署配置。示意图中的控件和数值不构成最终 API、默认参数或验收指标。

后续实现仍需确认数据规模、预设案例、具体模型或分词配置、版本兼容性和验收样例。需要真实检索支持的数值必须从实际结果生成；不能把概念图中的分数写成演示系统的固定输出。

图片使用 Codex 内置生图工具生成。完整输入保存在 [生图提示词](image-prompts.md)，便于在讨论后迭代。所有图像均为设计概念稿，未使用现有电影海报作为输入。
