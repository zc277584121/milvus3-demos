# Movie Catalog notice

This revision is fully synthetic. Every film title, synopsis, genre, year,
region, runtime, and poster palette in `movies.json` is authored by the
milvus3-demos project for the Movie Discovery (faceted semantic search)
demonstration. The films are fictional and are not derived from any real film,
studio catalog, or public dataset. None of them depict real actors, real
franchises, or existing film companies.

Posters are not included in this revision. The `poster_path` values are
placeholders and the `poster_palette` values are authored color hints; no image
bytes are redistributed yet. When posters are added, they will be original
project-generated illustrations with their own hash manifest and this notice
will be updated.

(https://creativecommons.org/publicdomain/zero/1.0/); see `licenses/LICENSE.txt`.
No third-party attribution applies because no third-party content is included.
